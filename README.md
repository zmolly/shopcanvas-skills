# Shop Canvas skills (public)

**Dual distribution:** this public repo is the MIT **stub** (steering wheel). Full sync recipes and scripts stay private/buyer-gated in [`zmolly/shopcanvas`](https://github.com/zmolly/shopcanvas).

## Install

```bash
npx skills add zmolly/shopcanvas-skills --skill shopcanvas-setup
```
